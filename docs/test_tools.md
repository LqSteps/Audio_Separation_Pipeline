# test_tools/: Ferramentas de Teste

- **[video_gen.sh](../test_tools/video_gen.sh):** Gera vídeos dummy/sintéticos com layouts variados, ruídos, silêncios e textos na imagem. Útil para validar se todo pipeline responde bem a múltiplos cenários e layouts de áudio, simulando arquivos reais.

---
> Essencial para depuração rápida, regressão e para novos desenvolvedores testarem o pipeline sem material sensível.
