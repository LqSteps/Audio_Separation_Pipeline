# run_info/: Monitoramento

Scripts para monitorar em tempo real o que está ocorrendo no pipeline.

- **[progress.sh](../run_info/progress.sh):** Exibe, em tempo real, informações do arquivo e progresso atuais processados pelo Demucs (usando arquivos temporários).
- **[queue.sh](../run_info/queue.sh):** Exibe a fila de arquivos sendo processados, útil para acompanhar lotes ou detectar gargalos em tempo real.

---
> Execute com permissões adequadas, normalmente via sudo, para acessar arquivos e diretórios geridos pelo pipeline.
